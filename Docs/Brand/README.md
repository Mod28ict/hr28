# CIP brand (Campaign Intelligence Platform)

The product's own brand (owner decision, 2026-10-13). Each client still sees only their own
campaign branding in the app; CIP appears there only on a new deployment before the client
sets theirs (see CLAUDE.md, "Each client sees only their own branding").

| File | Use |
|---|---|
| `cip-icon.svg`, `cip-icon-512.png` | App icon / square mark: profile pictures, slides, favicon source |
| `cip-logo.svg`, `cip-logo-1280.png` | Mark + "CIP" + "Campaign Intelligence Platform": quotations, documents, website |

- Mark: "Insight C", a C with three rising bars (campaign results growing). In the app it is
  `HR28.Web/Views/Shared/_CipMark.cshtml` (single colour, takes the colour around it).
- Colours: blue gradient `#2563eb` → `#60a5fa`; text `#0f172a`, caption `#475569`.
- Keep clear space of at least a quarter of the icon's width around it; don't stretch,
  recolour the bars separately, or put the white mark on a light background.
